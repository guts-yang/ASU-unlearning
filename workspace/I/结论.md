# 方向 I 当前结果与结论

记录时间：2026-10-29T13:47:25+08:00。数字来自本次 E0 日志与 [derived/e0_selection.json](derived/e0_selection.json)。未跑的项目写「未运行」。

## 问的是什么

在同一基座、同一 forget/retain 样本上，全层统一的 SwiGLU gate 温度 τ_M 能否在 Attention 温度 τ_A 之外给出可分离的遗忘信号：目标事实的 gold-token log-probability 下降，同时 retain 答案 NLL 不超过预先写死的上限。

这一步只测冻结 Teacher 的前向，没有训练 Student。

## 实际跑了什么

- 基座：`locuslab/tofu_ft_llama2-7b`，32 层。图里的 16 层是 Llama-3.2-1B 示意，本次没有使用。
- 数据：TOFU forget05 task 1，以及按问句长度匹配的 retain50。偶数作者为校准，奇数作者为 holdout。各 100 条 forget、100 条 retain。
- 条件：T00（τ_A=1，τ_M=1）；T10 只加 Attention 温度；T01 只加 gate 温度。网格是 1.5、2.0、2.3，作用在全部 32 层。
- 实现：τ_A 调用现有 ASU Llama 的 `attention_temp`（FlashAttention2）。τ_M 只在 `workspace/I/mcsd/teacher.py` 里把 gate 预激活除以温度。没有改 `Right-to-be-forgotten` 源码。
- 选温规则在出结果前写在 [configs/e0_probe.yaml](configs/e0_probe.yaml)：forget 的作者 bootstrap 区间下界必须大于 0，且 retain ΔNLL 均值不超过校准集 T00 retain 作者 NLL 的两倍标准误。多个合格温度时取最小温度。τ_M 还要落在所选 τ_A 的 forget 降幅 10% 以内。

retain 上限当场算得 **0.0034702592157625847**。T00 校准 retain 作者 NLL 均值是 **0.010823413909826739**，标准误 **0.0017351296078812924**。

每条条件 400 行，耗时 16.7–17.1 秒，峰值显存 13897.8 MB。

## 校准结果

S_forget 是答案 gold token 的平均 log-probability 相对 T00 的下降（nat，下降为正）。delta_nll_retain 是 retain 答案 NLL 的上升。

| 条件 | 温度 | S_forget | retain ΔNLL | 是否合格 |
|---|---|---|---|---|
| T10 | 1.5 | 0.290952 | 0.283142 | 否 |
| T10 | 2.0 | 1.903822 | 1.960206 | 否 |
| T10 | 2.3 | 2.694505 | 2.783960 | 否 |
| T01 | 1.5 | 0.378958 | 0.349824 | 否 |
| T01 | 2.0 | 1.634325 | 1.669364 | 否 |
| T01 | 2.3 | 3.445538 | 4.126917 | 否 |

六档的 forget 区间下界都大于 0。六档都不合格，因为 retain 上升都远大于 0.003470。最小的 retain 损伤是 T10、τ=1.5 的 0.283142。

ASU 常用的全层 τ=2.3 在这里是 T10：forget 下降 2.694505，retain 上升 2.783960。只加热 gate 到 2.3 时，retain 上升 4.126917，大于 forget 下降 3.445538。

## 结论

1. 按写死的规则，E0 不通过。判决是 `do_not_start_e1`，见 [gates/e0.json](gates/e0.json)。没有选出 τ_A* 或 τ_M*。
2. 在这张全层网格上，Attention 温度和 MLP gate 温度都把 forget 与 retain 一起推高。本规则要求的「forget 动、retain 几乎不动」没有出现。
3. Student 训练、T11、交互量 I_AM、错误实体替代率、生成连贯性、再学习攻击都未运行。因此不能说双通道优于只加 Attention，也不能说 MLP 通道没有作用。没有匹配强度的 T11，这两个说法都没有被这次实验判决。
4. 这次测的是 Teacher 输出相对 T00 的位移，不是训练后的 Forget Efficacy 或 Model Utility。不能用这张表否定或肯定已有的 ASU 训练复现。
5. 温度改变了输出，并不说明目标事实存放在 Attention 或 MLP 里。因果定位需要激活 patching 和随机模块对照，本次没有做。
6. 看过校准结果之后，不再改 [configs/e0_probe.yaml](configs/e0_probe.yaml) 的上限或网格。若要继续，先另写一条新规则，再重新跑 E0。

Holdout 上的同向位移已经记在选择文件里，但没有用来挑温度，也没有用来改判决。
