# ASU 遗忘流程（业务语义扩展版）· 分步实现说明

> 配图：`ASU_遗忘流程图_业务语义扩展版.drawio`（在原图《ASU_核心思想逻辑流程图》基础上扩展）。
> 图中节点全部为业务语义；本文按执行顺序讲代码级实现，行号即证据（仓库 `open-unlearning/`，分支 `fuxian`）。
> **重要**：图中"阈值判定 / 效果判定 / 异常兜底"三个环节是按论文语义补全的闭环，代码现状是离线人工完成——每步都标了【代码现状】。

## 分步说明（按图中执行顺序）

### 1. 触发遗忘条件
- **做什么**：确认要抹除哪部分知识、保住哪部分能力。实现上这不是运行时事件，而是**启动一次遗忘任务时的配置选择**：遗忘范围由数据划分决定（`configs/experiment/unlearn/tofu/default.yaml:15-17`，`forget_split=forget10 / retain_split=retain90 / holdout_split=holdout10`），被遗忘的对象是先做过全量微调的检查点（`default.yaml:13` 的模型路径）。
- **状态变更**：装配两个数据集并包装成"逐步配对"结构（`src/data/__init__.py:57-62` → `src/data/unlearn.py:34-46`）；同时准备原模型副本作参照（`grad_diff.py:16-23`，`deepcopy + eval()`，前向包 `no_grad`）。
- **为何这样做**：遗忘与保留必须在同一步内成对出现，否则更新信号会失衡；参照副本让"拉近/对齐"类目标有锚点。
- **参数影响**：forget 划分越小（forget01 vs forget10），单条目标知识的"遗忘压力"越分散，通常需要更多轮次。

### 2. 保留效用信号（保留集通路）
- **做什么**：每一步在保留集上前向，计算"能力保持"损失。两种口径：直接拟合答案（NLL，`grad_diff.py:28-29`）或与原模型输出分布对齐（KL，`trainer/utils.py:17-31`）。
- **数据流转**：保留集样本是**每步随机抽一条**与遗忘样本配对（`unlearn.py:39` 有放回采样），epoch 长度由遗忘集决定（`unlearn.py:20-25`）——保留集不保证全遍历。
- **为何这样做**：提供与遗忘方向相反的梯度，防止"抹知识"退化成"抹语言"。
- **参数影响**：`retain_loss_type=NLL` 拟合更直接但可能过拟合保留集；`KL` 更稳但显存翻倍（多一份冻结副本），且 baseline 的 KL 实现未掩 padding（`trainer/utils.py:21-31`），与 ASU 自己带掩码的口径不同，跨方法对比要注意。

### 3. 计算记忆衰减权重（升温平滑）
- **做什么**：教师侧前向时对注意力打分做温度缩放：eager 路径把注意力 logits 除以 `√d·τ`（`my_llama.py:421-425`）；sdpa/flash 路径对 Q、K 各乘 `1/√τ`（`my_llama.py:531-534 / 670-673`），三路等效于 `QKᵀ/(τ·√d)`。
- **机制含义**：τ>1 使 softmax 变平——高置信（尖锐）的事实关联权重被压低，宽泛的语法模式相对保留。这就是图中"记忆衰减权重"的物理来源：**衰减的是注意力分布的尖锐度，不是参数**。
- **【代码现状】**：缩放强度是静态超参，按层生效的开关（`my_llama.py:1022/1034` 支持 `layers_id`）在遗忘调用处没有透传（`ASU.py:38` 只传了温度）——想只烫平某些层目前不生效。
- **参数影响**：τ 是全流程最敏感的旋钮：τ→1 退回原模型（遗忘不动）；τ 过大教师分布趋近均匀，"有界拉近"会退化成"推向乱码"。

### 4. 平滑强度阈值判定
- **做什么（图中语义）**：用升温教师试答遗忘问题，输出连贯 → 采用当前强度；出现乱码 → 判定过强。
- **【代码现状】**：**没有运行时自动校准**。τ 由论文的二分搜索离线选定（TOFU 恒约 2.3，经验上超过 4 产生乱码），代码默认 2.0（`configs/trainer/ASU.yaml:6`）。图中的判定节点对应论文里的离线搜索流程，复现时应显式指定 τ，不要依赖默认值。

### 5. 遗忘信号（有界拉近）
- **做什么**：学生模型在遗忘集上前向，与升温教师逐位置做分布对齐（`ASU.py:34-47`）：两侧都取 `log_softmax`，逐位置 KL 求和后用答案掩码过滤（`ASU.py:80`），再按序列平均（`ASU.py:83`）。
- **为何这样做**：目标不是"把正确答案的概率推到无穷低"（对照路线的硬性推离，`grad_ascent.py:13` 的 `-CE`，无上界），而是"向一个仍然连贯、但事实被烫平的分布看齐"——损失有界，输出才不会崩成乱码。这是 ASU 与 GA 的本质区别。
- **数据流转**：只对答案段计算（prompt 段标签为 -100，`src/data/utils.py:124`），每步遗忘 batch 与保留 batch 独立前向、权重共享。

### 6. 联合目标（合并与更新）
- **做什么**：两路信号标量加权合并后一次反传（`ASU.py:102`：`loss = α·遗忘 + 保留`；基类约定是 `γ·遗忘 + α·保留`，`grad_diff.py:60`）→ HF Trainer 单优化器、全参数更新。
- **【代码现状·注意】**：ASU 实现丢掉了 γ 且 α 语义与基类相反（调 `alpha` 实际控制遗忘强度）；NLL 分支下打印用的参照损失是占位 0（`ASU.py:67`）。复现前建议先修齐系数口径。
- **参数影响**：遗忘权重越大抹得越快但效用损失风险越高；学习率 1e-5、10 轮、1 轮 warmup（`default.yaml:44-47`，warmup 由 `trainer/__init__.py:33-42` 换算成步数）决定收敛节奏——lr 过大会直接把分布推向对照路线的失败模式。

### 7. 遗忘效果判定（每轮末）
- **做什么（图中语义）**：三问——目标事实答不出？通用能力保持？输出连贯？
- **【代码现状】**：训练循环内**没有早停或在线判定**；判定发生在训练结束后的独立评测（`src/eval.py` → `evals/base.py:64`），指标为遗忘侧（问答概率/ROUGE、真值比率、遗忘质量）与效用侧（模型效用）成对出现（`configs/eval/tofu.yaml:5-11`）。图中的"每轮末判定"是把离线评测语义前置成闭环，复现时可按轮保存检查点后逐个评测实现。
- **分支**：达标 → 第 8 步写回；未达标 → 虚线回到学生模型继续下一轮（对应加大轮数/权重/温度重跑）。

### 8. 写回与失效
- **做什么**：遗忘不是删数据、也不是维护外部索引——**失效完全通过权重覆盖实现**：训练结束后把新参数写到输出目录（`src/train.py:61-62`），评测产物随之落盘（JSON 汇总）。此后所有推理都用写回后的模型，旧知识在参数层面失效。
- **【代码现状】**：保存策略的中间检查点被注释掉了（`default.yaml:48-49`），默认只有最终一份权重——一旦训坏没有中间版本可回退。

### 9. 异常兜底（乱码 / 过度无知）
- **做什么（图中语义）**：训练中或判定时发现输出退化为乱码（平滑过强）或过度无知（遗忘信号过强），回退到最近安全检查点，调低平滑强度或遗忘权重后重启。
- **【代码现状】**：**无自动回滚机制**。当前唯一兜底是人工调参重跑（τ 调小、遗忘权重调小、轮数减少）；加上没有中间检查点，兜底成本 = 整次训练重来。这是后续工程化最值得补的一环（按轮存档 + 连贯性在线探针）。

## 原图 → 扩展图的新增环节对照

| 新增环节 | 在原图中的位置 | 补全理由 |
|---|---|---|
| 触发遗忘条件 | 新增入口条（机制假设之下） | 原图直接从数据集开始，缺"遗忘范围如何划定" |
| 计算记忆衰减权重 | 遗忘集 → 冻结教师 之间 | 原图把"升温"写在教师节点描述里，未单独成步 |
| 平滑强度阈值判定 | 教师之后的新分支节点 | 对应论文的二分搜索定温；代码现状为离线超参 |
| 遗忘效果判定 + 未达标循环 | 联合目标与输出之间 | 原图是单向直线，缺"训练-判定-再训练"闭环 |
| 异常兜底 | 右下新增，红虚线 | 对应"过强 → 乱码"的失败模式与回退路径 |
| 写回语义 | 输出节点文案明确"写回" | 强调失效发生在权重层，而非数据/索引层 |

## 关键参数速查

| 参数 | 作用点 | 过小 | 过大 | 现值/出处 |
|---|---|---|---|---|
| 平滑强度 | 教师分布摊平程度 | 遗忘不动 | 教师趋近均匀 → 拉向乱码 | 论文二分搜索≈2.3；代码默认 2.0（ASU.yaml:6） |
| 遗忘权重 | 抹除速度 vs 效用 | 抹不净 | 退化为硬推离 | 1.0（注意 ASU 里 α 实际控制遗忘，ASU.py:102） |
| 保留口径 | 效用保持方式 | — | KL 显存翻倍、未掩 padding | NLL 默认（ASU.yaml:10） |
| 轮数 / lr | 收敛与过遗忘 | 抹不净 | 过度无知 | 10 轮 / 1e-5（default.yaml:44-47） |
| 检查点 | 兜底可回退性 | — | 无中间版本，训坏重来 | 默认关闭（default.yaml:48-49） |
