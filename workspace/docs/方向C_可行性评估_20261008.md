## 1. 评估摘要

### 1.1 一句话判决

**方向可继续，但必须换赛道投：从"新问题 + 机制创新"退为"方法/效用贡献"，并先补两项判定（FE 噪声模型、λ 网格）再定稿。**

### 4.2 归因链条的实际形状

原设计的链条是：

```
M0（derivation 对 τ 敏感） → M0b/M0c（derivation 被选择性伤害） → 锚定 derivation 行 → 修复
                                        ↑ 断点
```

实测链条是：

```
P1（推理退化）→ P4（注意力整体弥散化）→ 任意形式的注意力图保持 → 修复（GSM8K 回到基座）
```

**P4 这一段是本次实验最有价值的正面产出**，且原设计完全没预料到（原设计预期 derivation 受损最大）。它把方法的**因果位置**从"推导指针"移到了"注意力分布的整体保真度"。

## 6. 判据与统计审计（本报告的核心批评）

### 6.1 `stop_anchor` 触发的直接原因是判据设计，不是方法失败

预注册判据是"**FE 不掉**"——一个**零容差**判据：

- FE 是**有限样本的随机估计量**，任何有限样本下 `FE_anchor ≥ FE_ASU_KL` 几乎必然以概率 ~0.5 被违反；
- 若两 run 真实等效（H0 成立），仍有约 50% 概率触发 `stop_anchor`；
- 换言之，**这个判据把抛硬币当成了判决**。

**修订建议（P0）**：把"FE 不掉"量化为

```
FE_anchor ≥ FE_ASU_KL − 1·SE(FE)          # SE 由 ≥3 个种子估得
```

并在预注册里写明容差来源（种子方差 / 评测方差 / 置信区间）。

### 6.2 FE 的 −0.008 是回归还是噪声？（决定命运的一问）

现有信息：单种子、无区间、无重复评测，FE 的变化量 **−0.008（相对 −1.52%）**。

| 情形 | 若成立，结论 |
|---|---|
| σ(FE) ≳ 0.008 | `stop_anchor` 是**假阴性**，应继续，无需改方法 |
| σ(FE) ≲ 0.002 | 是**真实回归**（约 4σ），`stop_anchor` 成立，需调 λ 或改方法 |
| 介于之间 | 需增大种子数才能判 |

**P0 动作**：至少 3 个种子（或同一 checkpoint 的重复评测）报出 FE 的均值 ± 标准差。**这一步不做，方向存续结论无法定稿。**

### 6.3 M0c 判定的稳健性（可能翻盘）

`not_selective` 用的是**绝对 ΔEntropy**，但只给了 derivation 的基线熵（1.4846 nat）。

- 三类 token 的**基线熵不同**（function 常为高熵虚词），而绝对差受基线约束（上界 ln L）；
- 若 function / factual 的基线熵显著更低，**按相对增幅排序可能不同甚至反转**；
- 另需确认：标注里的"最终答案"是否就是三分类中的 `factual`，**是否有 token 重叠**（GSM8K 最终答案是数字，可能与 derivation 抽取规则相撞）。

**P1 动作**：补 function / factual 基线熵 → 同时报绝对与相对两套排序；核实类别无交叠。

### 6.4 对照的可用性（F5）

| 对照 | GSM8K | FE | 问题 |
|---|---:|---:|---|
| anchor | 75.21% | 0.518 | — |
| logit | **46.63%** | 0.516 | 比 ASU_KL 低 **24.79pt**，是**有害扰动**而非常规锚定对照 |

- **它成功排除了**最粗的替代解释："只要多训一轮就能涨 GSM8K"；
- **它没有排除**较弱但更常见的替代解释："**任何形态合理、尺度对齐的 retain 侧正则**都能涨 GSM8K"；
- anchor 帕累托支配 logit，说明该对照**没有竞争力**，作为方法对照不合格。
- 另注：训练中记录到 logit 损失仅 **0.0015**，而 ASU_KL 训练损失 0.105、L_anchor 0.0024 —— **损失尺度差 50~100 倍**，尺度未对齐 → 该对照的"同等强度"前提不成立。

**P0 动作**：给出 logit_control 的精确定义（作用量、目标、温度、权重），并**另设一个尺度对齐的中性对照**（同参数量、同训练步数、作用于非注意力量，期望效应 ≈ 0）。

### 6.5 命名与预注册污染（F6）

同一锚定系数出现三个符号：大纲 `μ=1`、评估报告 `λ_anchor ∈ {0.01,0.05,0.1}`、实际目录 `beta0.1`。

- 判定：`beta0.1` **疑为 λ_anchor = 0.1（网格上限）**，而非 μ=1；
- 后果：**λ 网格实际未做**，只在**最激进点**取了单点。而"FE 掉一点、GSM8K 大涨"恰恰是 λ 偏大的典型症状 → **最有可能同时满足两判据的 0.05 / 0.01 从未被试**。

**P0 动作**：统一命名（建议统一为 `λ_anchor`），并把大纲 M1 行的 `μ=1` 更正。

## 7. 交叉综合：叙事必须怎么改写

### 7.1 死掉的部分

- ❌ 标题级主张"ASU 的二分法漏掉推导 token → 平滑**误伤推导**"：M0c 直接否证。
- ❌ 方法-机制绑定"锚定 **derivation 行** 以保护推导指针"：靶位归因不成立（F3）。
- ❌ 潜在卖点"我们是第一个指出平滑的选择性伤害"：不是选择性伤害（M0c）。

### 7.2 存活并可撑起一篇的部分

**新叙事（建议）**：

> 平滑族遗忘的代价不是"选择性误伤某类 token"，而是**注意力分布的整体保真度损失**（over-smoothing）；在 retain 侧加一个**轻量的注意力图保持正则**，即可在 ~0.8pt FE 的代价下把推理能力恢复到基座水平。

这个叙事的三个支点都已有数据：

| 支点 | 证据 |
|---|---|
| 损伤是整体的，不是特异的 | M0c：三类位置全涨且与关键性反向 |
| 修复有效且便宜 | M1：GSM8K +3.79pt，恢复基座 99.6%，1 次正则、无搜索 |
| 排除了最粗替代解释 | M1：logit 对照 46.63% |

### 7.3 新叙事的新风险（必须在下一次评估里处理）

1. **撞车风险升高**：从"新机制"改为"通用注意力/表征保持正则"后，落入一个**更拥挤**的赛道（遗忘中的 representation/attention preservation 类正则）。→ 这正是需要重新跑**先占审计**的原因（§9 P2-1）。
2. **新意稀释**：注意力图保持是相对常识的做法，**必须有一个非显然的可迁移组件**（例如：按 M0c 实测 Δ 加权的位置选择、或 λ 与 τ 的联合调度），否则只是工程补丁。
3. **claim 强度**：FE 代价一旦是真实的，就必须写成 **trade-off 方法**（给 Pareto 曲线），而不是"免费修复"。

| **K4 中性对照** | 尺度对齐的中性对照不显著优于 ASU_KL | 若显著优越 → 方法的特异性被推翻，降为工程补丁 |

## 9. 优先级修订建议

### P0（做定稿判决之前必须先做）

1. **补 FE 噪声模型**：≥3 种子或重复评测，报 FE 均值 ± SD，据此判定 −0.008 是否显著（§6.2）。**这是方向存续结论的唯一缺口。**
2. **跑 λ_anchor 网格 {0.01, 0.05, 0.1}**：网格本来就在计划里，成本 ≈4 小时（单次 74 min）。这是最有可能**同时满足两条判据**的一步。注意 **λ 更小 → FE 代价更小、GSM8K 增益也可能更小**，故需报 **GSM8K–FE 帕累托点**，而不是单点。
3. **重设中性对照**：给出 logit_control 精确定义 + 加入一个尺度对齐、期望效应≈0 的中性对照（§6.4）。
4. **统一命名**：`μ` / `β` / `λ_anchor` 归一，更正大纲 M1 行的 `μ=1`（§6.5）。

### P1（叙事与文档层）

5. **改写叙事**：按 §7.2 把主张从"推导锚定/选择性误伤"改为"注意力弥散化修复"，并同步更新 `方向C_DA-ASU_概念大纲.md` 的标题级描述与 `方向C_创新评估报告.md` 的五维雷达（Higher/Stronger 两档需下调，Cheaper 仍成立）。
6. **补 M0c 的稳健性**：function / factual 基线熵 + 相对排序 + 类别交叠核实（§6.3）。
7. **更新风险登记与 kill-switch**：用 §8 的 K1–K4 替换原表。

### P2（结构性）

8. **重跑先占审计**（必做，且在叙事改写**之后**）：新叙事（通用注意力保持 + 遗忘）比原叙事拥挤得多，必须先确认残余间隙。
9. **确定可迁移的非显然组件**：若要保住"超出工程补丁"的定位，需要一个别人不会自然想到的组件（候选：按 M0c 实测 Δ 加权的**损伤对齐锚定**；或 λ–τ 联合调度）。
10. **修仓库流程**：方向分支→`new_method` 的合并须校验判决文件是否随行（§2.3），并考虑用 README 维护规则固化。

## 10. 结论（逐题回答）

| 问题 | 回答 |
|---|---|
| **方法有效吗？** | **有效。** anchor 把 GSM8K 从 71.42% 恢复到 75.21%（基座 75.51% 的 99.6%），代价 0.8pt FE；logit 对照 46.63% 排除了"多训即涨"。 |
| **原机制成立吗？** | **不成立。** M0c 判定损伤是整体弥散而非选择性；且锚定打的是受损最小的位置仍有效 → 收益与"推导指针"无关。 |
| **`stop_anchor` 该接受吗？** | **作为判据级停机，接受**（预注册三判据未同时满足，程序正确）。**作为方向级死刑，不接受** —— FE 的 0.008 未经噪声校准，且判据本身零容差、λ 只跑单点。 |
| **方向还能继续吗？** | **能，但换赛道。** 从"新问题 + 机制创新"改为"**方法/效用贡献**"：注意力弥散化的诊断 + 轻量锚定修复 + FE–GSM8K 帕累托。 |
| **能不能投 CCF-A？** | **现状不能**。缺三样：① FE 噪声/容差（P0-1）② λ 帕累托曲线（P0-2）③ 与通用注意力保持类工作的差异化与非显然组件（P2-8/9）。补齐后可投 B 会/workshop 起步。 |
| **最省算力的下一步是什么？** | **P0-2（λ 网格）** —— 4 小时算力，直接决定是"trade-off 不可避免"还是"存在同时满足点"。 |
| **最大的未知是什么？** | FE 的 0.008 是噪声还是真实回归。**它一个数决定方向是"继续"还是"重构"。** |
