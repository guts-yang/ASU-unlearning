## 2. 口径与风险（开评前必须澄清）

### R1 ⚠️ 命名口径与计划不符：`beta0.1` vs `μ=1`（部分澄清，仍未闭合）
- 计划（大纲 M1 行）：锚定强度 **μ = 1**；
- 创新评估报告 §7 行动 2：**λ_anchor 网格 {0.01, 0.05, 0.1}**；
- 实际权重目录：`..._beta0.1_anchor` —— **数值 0.1 恰为该网格的上限**，故 β 极可能就是 λ_anchor。
- **结论**：同一系数在三处有**三个名字**（μ / β / λ_anchor），且只跑了网格**最大点**。
  → 需统一命名；且"μ=1"与"λ=0.1"不是一回事，**大纲 M1 行的 μ=1 应视为笔误或另一系数**，必须澄清。
  → 附带影响：**λ 网格未做**，只有单点 0.1（最激进点）。这直接决定下一步该往哪个方向调（见评报告 P0-2）。

### R2 ⚠️ logit 损失 0.0015 过小 → 对照可能退化为"零扰动"
- 若该损失未归一、或其权重被其他项压制，对照实际近似"不做额外约束"，则**无法排除"任何额外训练量都能涨 GSM8K"**，对照失效。
- **需给出**：该损失的定义（logit-KL？温度？）、权重、与其他项的尺度关系。
- 与之对照：ASU_KL 训练损失 0.105，anchor 的 L_anchor 0.0024 —— 三者量级差 50~100 倍，**必须先确认它们是否可比**。

### R3 ⚠️ 两条对照的除目标项外必须逐项一致
anchor 与 logit_control 需同超参、同数据、同步数（62 ✓）、同随机种子、同评测口径。**任何一个自由度不同，对照即失效**。

### R4 anchor 损失 0 → 0.0024 的含义有限
损失从 0 起说明锚定项初始无偏差（学生=基座起步），升至 0.0024 说明**有梯度在起作用**；但绝对值极小，**不能据此判断注意力图是否真被约束住**。
→ 判据应是 eval 时的 **attention-map KL / MSE**，而不是训练损失。

## 3. 因 M0c（`not_selective`）产生的设计含义

M0c 判定注意力是**整体**变糊、且 derivation 是受影响**最小**的位置 → 大纲 §2.2 原设计"**仅锚定 derivation 行的注意力行**"**靶位打错**。

因此本次已完成的 `anchor` 运行，其角色应重新定义为：
- 若它仍能提升 GSM8K → 说明锚定收益**与靶位无关**（更像通用正则效应），原机制解释进一步削弱；
- 若不能提升 → 支持"靶位重要"，为改锚全位置 / 按 Δ 加权提供依据。

**结论：本次 anchor 不再是"方法有效性验证"，而是"错靶对照"** —— 无论结果如何都有信息量，但**不足以支撑"推导锚定"作为机制卖点**。

### 5.3 判决：`stop_anchor`（判据级）

- **性质**：这是**预注册判据级的停机**（FE 不许降这一条被硬约束卡住），**不等于方向级死刑**。
- **实际达成的**：GSM8K 从 71.42% 提到 **75.21%**，即**在 0.8pt FE 的代价下把推理能力恢复到基座水平（75.51%）的 99.6%**；logit 对照在 GSM8K 上低 28.6pt，**排除"任何额外训练都能涨 GSM8K"**。
- **不能声称的**：本次 `anchor` **按原设计只锚 derivation 行**，而 M0c 已判定 derivation 是受损**最小**的位置 → **收益无法归因于"保护推导指针"**。收益更可能来自**通用的注意力图保持**（见评报告 §7）。
- **待解决**：FE 的 0.008 是否在噪声内（单种子，无区间/无方差）—— 决定 `stop_anchor` 是真回归还是假阴性（见评报告 §6.2）。
