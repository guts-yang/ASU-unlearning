| 位置 | 角色 | ΔEntropy (nat) | 相对增幅 | 排序 |
|---|---|---:|---:|---:|
| `derivation` | **target** | **+0.0306** | **+2.06%**（base 1.4846） | 最小 |

**严格表述**：结论不只是"不特异"，而是**显著反序** —— derivation（本该最受损）反而是三类中受扰**最小**的，且 CI 完全落在负半轴。单调性 derivation < function < factual。

## 3. 对命题的影响

| 假设 | 状态 |
|---|---|
| **H1 的"特异性"读法**（平滑选择性误伤推导指针） | ❌ **被否证** |
| **H1 的"三分类"读法**（derivation 不等同 function） | ⚠️ 未被否证，但已不足以支撑"误伤"叙事（M0 层面的可分性仍成立） |
| **H2**（注意力模糊化模式**泛化**到一切计算场景） | ✅ **得到支持**（GSM8K 位置被无差别糊化） |

**claim 必须重定位**：从「选择性误伤推导指针」→「**全局注意力弥散化**的副作用」。后者仍能解释 GSM8K / ARC-c 掉分（多步推理对注意力精度更敏感），但**新颖性弱于原叙事**，且与 ASU 原文"function token 不敏感"的说法构成**正面冲突**（实测 function 熵增最大之一）。

**与 M0 的表面张力（须在文中解释）**：
- M0：frozen base 上 τ 升温，derivation 的 NLL 斜率最大（d=1.17）；
- M0c：ASU_KL 训练后，derivation 的熵增最小。
两者是**不同量**（对 τ 的边际敏感度 vs 训练后的熵水平位移），**不构成逻辑矛盾**；但必须在同一段里给出统一解释，否则审稿人必然追问。一种可行的调和：τ 敏感性说明"derivation 依赖精确注意"，而 ASU_KL 的优化路径并未把额度花在 derivation 上（梯度落点由 forget set 决定，不由 GSM8K 的 token 类决定）。

## 4. 关键动作与待确认

### 4.1 方法件靶位错配（最重要）

概念大纲 §2.2 原设计 **"仅锚定 derivation 位置的注意力行"** —— 而 M0c 显示 derivation 恰是**受影响最小**的位置。**靶位打错了**。

| 选项 | 说明 | 代价 |
|---|---|---|
| A. 锚定改为**全位置**（全注意力图对齐基座） | 与"全局弥散化"叙事一致，最保守 | 可能压制 forget 侧（与 ASU 目标冲突）→ 需 μ 网格 |
| B. 锚定**按 Δ 排序/加权**（factual·answer 行权重最高） | 精准对冲实测损伤位置 | 引入调参，且"按结果定权重"有过拟合审稿风险 |
| C. 保留"仅 derivation 行"作为**对照**（预期无效） | 把错靶当阴性证据，反证靶位重要性 | 需再来一次训练 |

> 现状：`anchor` 已按原设计（推导行）训完，其角色因此变为**"错靶对照"**——若它仍提升 GSM8K，说明锚定作用与靶位无关（更可能只是正则效应）；若不提升，则支持"靶位重要"。

### 4.2 判定稳健性待确认（可能翻盘）

1. **判据用绝对 Δ，但只给了 derivation 的基线熵（1.4846）**。若 function / factual 的基线熵不同，**按相对增幅排序可能不同甚至翻转**。必须先补两类的 base H，才能把 `not_selective` 定案。
2. **类别映射待确认**：`最终答案` 是否即三分类中的 `factual`？GSM8K 的最终答案是数字，可能与 derivation 的程序化抽取规则**重叠** → 先确认两类 token 无交叠，否则 DiD 的对照不干净。
3. **统计细节缺失**：n、CI 构造（bootstrap？）、平均方式（token 级 / 题级 / 加权）均未给出。
