### 1.2 总目标

\[
\mathcal L=\mathcal L_{\text{base}}+\lambda_1(\mathcal L_{\text{membership}}+\mathcal L_{\text{fact}})
+\lambda_2\mathcal L_{\text{cons}}+\lambda_3\mathcal L_{\text{geom}}
\]

- `base` ∈ {GA, NPO, ASU}，说明 RIU 与具体算法解耦；
- 两个探针都带 GRL：内层尽力解码，外层让模型不可解码；
- 事实身份标签由 `forget` 的 `index // 20` 得到（TOFU forget05 = 10 作者 × 20 QA）；
- 探针在 `HF Trainer` 构造前注册到 `model` 上，确保参数进入优化器。

## 2. 与完整规格的差距（诚实记录）

用户规格中的 R 是三类**保持效用但可重新激活知识**的变换。当前实现只做到了**可微代理**，不能冒充完整实现：

| 规格要求 | 当前状态 | 差距 |
|---|---|---|
| 语义保持变换：LeakRU 6 结构 + 跨语言 + 转述 | 未实现 prompt 级变换；仅 `identity/amplify` 代理 | 需要构造 `t(x_f)` 数据管线并做多视图前向 |
| K 步短微调 | `noise` 高斯扰动代理 | 无真实内层 K 步梯度上升 |
| INT8 量化 | `round` 激活级 STE 量化代理 | 未做权重级 INT8 模拟 |
| 第 1 步冻结模型训练探针并量化可恢复性 | 探针在线联合训练 | 缺独立离线探针评估器（下一步） |
| PCA top-k 事实子空间 | rank-1 运行差分方向（小 batch 下更稳） | 需离线大样本 PCA / rank-k 消融 |
| 恢复攻击下的 FQ / RR | LeakRU evaluator 源码不在磁盘上 | 只有配置与消费脚本，指标复现被阻塞 |

这些差距决定了当前阶段只能称为**机制验证（pilot）**，不能宣称 RIU 已降低任何泄露指标。

## 3. 一个必须写进论文的技术修正

提案 v5 Eq. 6.5 与用户补充材料都写：

\[
\mathcal L_{\text{geom}}=\big\|\mathrm{Proj}_{S_f^{\perp}}(h)\big\|^2 \quad\text{（最小化）}
\]

由于 \(\|h\|^2=\|\mathrm{Proj}_{S_f}h\|^2+\|\mathrm{Proj}_{S_f^{\perp}}h\|^2\)，**最小化正交补分量会把表示推向事实子空间 \(S_f\)**，与"擦除事实"的目标相反。

实现中提供两个模式：

- `geom_mode=as_written`：严格按提案公式；
- `geom_mode=corrected`（默认）：最小化 \(\|\mathrm{Proj}_{S_f}h\|^2\)。

建议论文里保留该消融：它既是自查，也能回应"为什么几何项方向如此选择"的 rebuttal。

## 4. 实验计划

1. **机制验证**：`geom_mode` 两模式 × `probe_target ∈ {membership, fact, both}`；去掉 GRL（退化为 v4 数据增强）作为核心消融。
2. **plug-in 通用性**：GA / NPO / ASU 各自 ±RIU，统一 forget05 / retain95 / seed 1001。
3. **指标**：FQ、RR、Robustness、\(R_{\max}\)、线性/核探针解码率、MMLU/BBH 效用；目前 FQ/RR 需先恢复 LeakRU evaluator。
4. **补数据**：≥3 seed、forget10、MP/DS 分母粒度、跨语言与 Quantization 攻击。
