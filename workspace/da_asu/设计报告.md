# 方向 C：DA-ASU 设计报告

DA-ASU（Derivation-Anchored Attention Smoothing Unlearning）修的是 ASU 的效用侧：注意力平滑在忘掉事实的同时，误伤依赖精确指针的数学推理。本报告描述当前仓库里已经落地的设计，对应代码在 `workspace/da_asu/`，训练入口在 `Right-to-be-forgotten/`。

## 1. 问题与假设

ASU 把 token 分成事实和功能两类。事实 token 依赖尖峰注意力，升温即遗忘；功能 token 不依赖，平滑后语言仍然流畅。这个二分漏掉了推导 token：算术中间结果同样依赖精确注意力，但它们属于保留侧。Table 2 上的损伤集中在 GSM8K 和 ARC-c，MMLU 几乎不动，与这个缺口一致。

当前实现检验两个假设，顺序不能颠倒。

- **H1（机制）。** 在冻结基座上，推导 token 的下一词负对数似然随注意力温度上升的斜率，应明显大于虚词。对照是 function，不是 factual。推导和事实如果一样陡，只说明它们共享同一种注意力依赖，不构成否决。
- **H2（迁移）。** 遗忘集上的平滑蒸馏如果把“注意力变糊”写进了权重，学生在与遗忘集无关的 GSM8K 推导位置上，注意力熵应高于基座。H1 成立只说明基座上的推导 token 怕升温；H2 才说明 ASU 训练把这种损伤带出了遗忘集。

## 2. 总流程

```text
GSM8K 标注
    -> M0  冻结基座 NLL-τ 扫描          否决 H1
    -> M0b 学生 vs 基座的推导行熵       否决 H2（不挡住训练入口）
    -> M1  ASU 遗忘损失不变
           + 锚定项 或 同位置 logit 对照
```

M0 的判决写在 `workspace/results/direction_c/m0_verdict.json`。`real_world_unlearn.py` 在 `da_asu.enabled=true` 时读取该文件，只有 `decision=proceed` 才允许训练。`allow_without_m0` 默认关闭。

## 3. Token 定义

位置 `t` 的注意力行形成的是预测 `t+1` 的隐状态。`D_tok` 因此标在 query 上，而不是标在推导 token 自己身上。这与 `asu_loss` 里 `labels[:, 1:]` 的错位一致。切词使用 Llama-3 词表的 offset map，多 token 数字按片标记。

三类跨度都落在答案字符串上，重叠时的优先级是 derivation、factual、function。

| 类 | 来源 | 实现 |
|---|---|---|
| derivation | `<<expr=result>>` 的右值 | `labels.py` 的 `result_char_spans` |
| factual | `####` 后的最终数字 | `spans.py` 的 `_FINAL_RE` |
| function | 封闭虚词表，且不落在计算器块或最终答案内 | `spans.py` 的 `FUNCTION_WORDS` |

`prepare_records.py` 把 GSM8K 写成 JSONL。记录里的 `factual_spans` / `function_spans` 可以被人工跨度替换；derivation 始终从答案文本重新抽取。问题侧 token 的 label 置为 `-100`，不进入斜率或损失。

这套 factual / function 是可运行的操作定义，不是论文附录 N 的 GPT-4o 标注。换标注只需改 JSONL 里的跨度，扫描和损失代码不用改。

## 4. M0：kill-switch

在冻结的 Llama-3-8B-Instruct 上，对全部层施加温度，τ 取 `1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0`。`layers_id` 为空时视为每一层，避免配置里的空列表把温度关掉。每个 τ 只做前向，记录三类 query 的平均 NLL。每道题对 NLL–τ 做一次线性回归，得到斜率。

统计单位是题目，不是 token。derivation 斜率减 function 斜率，在同时含两类的题目上配对。2000 次题目级 bootstrap，种子固定为 0。

否决条件（满足任一即 `kill`）：

- 配对斜率差的 Cohen's d 满足 `|d| < 0.2`
- 斜率差均值的 95% 置信区间盖住 0

配对题目少于 20 时判决为 `insufficient_data`，同样不能开训。derivation 对 factual 的同一套统计只写入 `taxonomy`，`role=report_only`，`kill` 恒为假。全局 τ 会抬高所有行的注意力熵，所以熵不进入 M0 判决。

入口是 `run_m0.py`。NLL 不需要注意力图，加载顺序为 FlashAttention、SDPA、eager。

### 已完成的 M0 结果

2026-10-08，一张 A800，GSM8K test 1319 题，batch 8，最大长度 512，约 7 分钟。判决 **proceed**。

| 对比 | 题数 | 斜率差均值 | Cohen's d | 95% CI | 作用 |
|---|---:|---:|---:|---|---|
| derivation − function | 1278 | 0.910 | 1.17 | [0.868, 0.953] | 否决项，通过 |
| derivation − factual | 1301 | 0.404 | 0.61 | [0.369, 0.441] | 只报告 |

推导 token 随温度变难的速度快于虚词，也快于最终答案数字。H1 按当前判据成立。

## 5. M0b：学生注意力是否变糊

M0b 比较基座和一份 ASU 学生在同一批 GSM8K query 上的注意力熵。熵是 `−Σ p log p`，`log` 为自然对数，单位是 nat。每题、每类先对层和头取平均。比较的是两个模型在 τ=1 下的行，而不是同一个模型被全局升温。

`decision` 只看 derivation。熵增按题汇总，95% bootstrap 区间盖住 0 或均值不大于 0 时判决 `stop_anchor`。写作时引用四位小数和文件里的 bootstrap 区间。效应量是配对 `d_z`：熵增均值除以该差的样本标准差（`ddof=1`）。它不是两组 pooled d，也不是 Glass's delta。`d_z` 大只说明题与题之间的差很齐。

同一前向还记录 function 和 factual 的基座熵、学生熵、熵增，以及每题熵增除以该题基座熵。特异性是同题的 derivation 熵增减 function 熵增。区间在 0 以上记 `selective`，盖住 0 或均值不大于 0 记 `not_selective`。这个标签只写入 `m0b_specificity.json`，`role=report_only`，不改 `decision`，也不覆盖 `m0b_verdict.json`。factual 同样只报告。

`run_m0b.py` 在 M0 不是 `proceed` 时直接退出。训练脚本目前不读取 M0b 判决；若 M0b 为 `stop_anchor`，锚定项应人工停掉。

2026-10-08，同一对基座与 ASU_KL，GSM8K test。`decision` 仍是 `proceed`。三类熵增的 95% bootstrap 区间都在 0 以上，function 和 factual 的增幅不低于 derivation。同题 derivation 减 function 的均值为 −0.0112 nat，区间 [−0.0118, −0.0107]，`d_z` = −1.16，标签 `not_selective`。推导行变糊了，但不是被选择性糊掉。

| 类 | 题数 | 基座熵 | 学生熵 | 熵增 | 95% CI | 相对增幅 | d_z |
|---|---:|---:|---:|---:|---|---:|---:|
| derivation | 1301 | 1.4846 | 1.5152 | 0.0306 | [0.0302, 0.0310] | 0.0206 | 4.28 |
| function | 1294 | 1.8019 | 1.8436 | 0.0417 | [0.0412, 0.0422] | 0.0230 | 4.29 |
| factual | 1319 | 1.6195 | 1.6714 | 0.0519 | [0.0512, 0.0525] | 0.0319 | 4.30 |

## 6. 训练目标

遗忘侧不动。`asu_loss` 仍是学生 logits 向升温教师的 KL，教师构造和 `attention_temp` 保持 ASU 原设置。real-world 配置是 ASU+KL、τ=2.0、5 epoch、batch 4、grad accum 4、两卡、`layers_id=null`。

保留侧每个 step 另取一个 GSM8K train microbatch，最大长度 512。两种模式用同一个 `mu`，默认 1.0，并且互斥，不能叠在同一次训练里。

**锚定（`mode=anchor`）。** 只取 derivation query 行，形状是 `[batch, heads, n_queries, seq]`，一层算完再释放，不保存 32 层完整注意力图。学生和基座都在 τ=1 下计算这些行。损失是各层、各头上 `KL(A_base || A_θ)` 的平均，基座行不反传。每 10 step 打印逐层 KL，用来区分“平均把复制头稀释了”和“锚定与遗忘在抢权重”。

**logit 对照（`mode=logit_control`）。** 同一 query 位置、同一 `mu`，改成 logits 上的 `KL(base || student)`，不读注意力图。这条对照用来回答 GSM8K 回升是不是因为模型看见了数学文本。

联合目标：

```text
L = λ L_ASU + L_R + μ L_extra
```

`L_ASU` 与 `L_R` 是现有的 forget / retain 项。`L_extra` 在两次运行中分别是 `L_anchor` 和 `L_logit`。遗忘侧继续走 FlashAttention；只有 `D_reason` 的锚定读出用 eager 的选中行。

M1 成立要三条同时满足，标准写在 `protocol.py`：

- Forget Efficacy 相对 ASU_KL 不降
- GSM8K 相对 ASU_KL 回升至少 3 个点
- 该回升高于同数据的 logit 对照

ARC-c 不在 M1 的承诺里。

## 8. 当前版本故意不做的事

- 不按头关闭 τ。变体 B 留到逐层 KL 显示锚定被平均稀释之后。
- 不用注意力熵否决 H1。
- 不把 GSM8K 最终答案的 NLL 直接加进锚定损失。锚定约束的是注意力行。
- 不在 M0 上复现 Table 2 的 −6.67pt。该对照留在 ASU_KL 训练后的 lm-eval。
