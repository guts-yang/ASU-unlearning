# R3-3 · 浅-深解耦双阶段遗忘（REVISE 候选）

> **状态提醒**：按"未淘汰作为候选"保留，但 V4 决策为 `REVISE`：方向仍有边缘信号，但 V2 的抑制失败模式重现且 retain 同步受损；**仅保留为消融，不投入主线训练**（来源：`IDEA_REPORT_V4.md`、`research_contract.md`）。这是三轮中证伪风险最高的候选。

## 0. 故事（30 秒讲稿）

> 有一个用户独有数据提出的科学问题：stage0 实测显示事实差异（last-token ΔA）在深层累积（L1 0.051 → L16 0.380），可 ASU 平滑浅层就有效——如果事实差异主要在深层显现，为什么平滑浅层能忘？一个诱人的解释是：ASU 浅层自蒸馏只切断了浅层的精确检索路径，深层仍残留事实表示，所以是"浅层遗忘"。于是设想两阶段：浅层继续用 ASU 平滑阻断信息流，深层在 ΔA 显著区（L10–16）把事实相关方向**拉向冻结基线在 retain 上的对应分布**（注意：不是 V2 已证伪的"沿 ΔA 抑制"），再接深度审计。故事的科学问题最有趣，但实测只给到边缘信号（L12 suppress $dF=+0.133$、$dR=+0.099$），严格阈值下通过数为 0，且与 V2 的抑制失败模式一致。因此它是一份带明确 kill switch 的消融候选，不是推进方向。

## 1. 领域问题与思路来源

- **stage0 张力**（`IDEA_REPORT_V3.md` §查新发现 2）：ASU 论文称事实锚定浅层、factual token 对 $\tau$ 远敏感；但用户 TOFU-1B stage0 实测 last-token ΔA 逐层递增。两种解释：(a) 浅层平滑截断信息流，深层差异根本形不成；(b) 深层 ΔA 主要编码**主体身份**而非事实（呼应 V2 "unpooled ΔA 与 wrong-donor 重叠 0.55"）。
- 这个张力是用户独有数据提出的科学问题，现有工作（ADU/ALMPU/RepSelect）都没回答。
- V2 已证伪"沿 ΔA 抑制"与"反事实渐进 schedule"；本候选必须换成"向 retain 对齐"才不重复死胡同。

## 2. 核心假设（可证伪，风险高）

**H**：ASU 只做浅层遗忘；分层处理——浅层 ASU 平滑阻断信息流，深层用 pooled ΔA basis（stage7b 已生成，证明与 retain 正交 0.23）把事实方向**向冻结基线在 retain 上的分布对齐**，可在不伤 retain 的前提下压缩深层残留，从而把遗忘变深。

**决定性 kill switch（V3 预注册）**：深层 ΔA 方向是否能在不伤 retain 的前提下被单独压缩——若压缩同时伤 retain → 与 retain 不可分 → 否决。V4 实测已命中该风险边缘。

## 3. 具体实现

- **阶段 1**：标准 ASU（可与 R2-B τ 课程叠加）。
- **阶段 2**：在层 10–16（ΔA 显著区）对 forget 输入 $X^+$ 的激活施加表示约束，把事实相关方向拉向**冻结基线在 retain 上的对应分布**（不是沿 ΔA 抑制、不是对齐 donor）。
- **阶段 3**：接 R3-2 深度审计（P1/P2/P3/INT8 + token 分层）。
- **等预算对照**：静态全层 / 手设渐进 / 反向 / 随机 schedule 互比；shuffle-layer 对照；L12 suppress 有无；retain 同实体非删除关系探针。

## 4. 当前证据与 REVISE 依据（provisional）

- V4：`gate=PASS` 但仅 L12 suppress 达标边缘（$dF=+0.133$、$dR=+0.099$）；严格阈值 $dF\ge0.15$ 且 $dR\le0.05$ 下**通过数 = 0**。
- 决策 `REVISE`：与 V2 抑制失败模式一致，仅保留为消融，不投入主线。
- V3 曾评 `Accept with Revisions` 五维 Higher8/Faster6/Cheaper6/Stronger6/Broader6，自述"三轮中证伪风险最高"；以 V4 实测为准。
- 跨模型评审不可用，裁决 provisional。

## 5. 差异化与失败模式

| 近邻 | 关系 |
|---|---|
| RepSelect (arXiv:2606.17168) | 用 forget 梯度 SVD 的 bottom-PC；本候选用反事实配对 pooled ΔA basis 这一用户独有资产 |
| ALMPU / ADU | head 扰动 / attention 路径；本候选切分浅/深两阶段 |
| V2 反事实配对全系（已 ELIMINATED） | 本候选刻意避开"沿 ΔA 抑制"，否则重蹈覆辙 |

**失败模式（已部分命中）**：压缩深层 ΔA 同时伤 retain；严格阈值通过数 0；V2 失败模式重现；把"对齐 retain"偷换成"对齐 donor/A⁻"。命中即维持 REVISE 或归档，不放宽阈值。

## 6. 与方向 I 基线 v0.6.1 的关系

- 共享关切：都注意到"事实差异在深层/答案阶段展开"。方向 I v0.6.1 的裁决正是把 $\mathcal L_F$ 作用域从 prompt 末位改到**答案跨度 $S_f$**，并要求 teacher-force 拼入 $y^+$、冻结 Teacher 在 $X^+\oplus y^+$ 上前向——与"浅层看不到答案实现"的关切同源。
- 机制相反：方向 I 去 $\tau$、用非 donor 中性约束；本候选保留 ASU 温度线、做浅/深解耦。两者证据链分开登记；方向 I 历史 pilot 不复用为 confirmation。
- 本候选可复用方向 I 基线 §6 的抗恢复与"非答案替换"硬口径做验收。
