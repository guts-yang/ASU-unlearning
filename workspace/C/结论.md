# 方向 C 预实验结论

归档时间：2026-10-28。实验日期：2026-10-08。  
结构化证据：`derived/m0_verdict.json`、`derived/m0b_verdict.json`、`derived/m0b_specificity.json`、`derived/m1_results.json`。

## 一句话

机制门过了；**anchor 能把 GSM8K 拉回来且不是 logit 糊弄，但以略损 Forget Efficacy 为代价，按预注册 M1 判据整体未过。**

## 核心设定

- 底座：`NousResearch/Meta-Llama-3-8B-Instruct`
- 遗忘：`ASU+KL`，τ=2.0，lr=5e-6，5 epoch，seed=1001，real-world 数据
- 额外项：`μ=1.0`；`anchor` = 推导 query 上 `KL(A_base ∥ A_θ)`；`logit_control` = 同位置 logits `KL(base ∥ student)`
- 辅助数据：GSM8K train（路径曾指向 `workspace/results/direction_c/gsm8k_train.jsonl`）

## M0 / M0b（机制）

| 关卡 | 判决 | 关键数字 |
| --- | --- | --- |
| M0：推导 − 虚词 NLL–τ 斜率 | **proceed** | 均值差 0.910，Cohen's d=1.17，95% CI [0.868, 0.953] |
| M0：推导 − 事实（仅报告） | pass / 不否决 | 均值差 0.404，d=0.61 |
| M0b：学生推导行熵增 | **proceed** | +0.0306 nat，CI [0.0302, 0.0310] |
| 特异性 | **not_selective** | 虚词/事实熵增 ≥ 推导；损伤存在但非选择性 |

结论：H1/H2 按协议成立，允许开训；但「只伤推导」不成立。

## M1（real-world 训练，三跑）

| 变体 | MU | FE | GSM8K | ΔFE vs 基线 | ΔGSM vs 基线 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ASU+KL 基线 | 0.6162 | 0.5259 | 0.7142 | — | — |
| DA-ASU **anchor** | 0.6169 | 0.5185 | **0.7521** | −0.0074 | **+3.79 pt** |
| logit_control | 0.6167 | 0.5159 | 0.4663 | −0.0100 | −24.8 pt |

预注册三条（须同时过）：

| 门 | 结果 |
| --- | --- |
| FE 相对基线不降 | **未过**（0.5185 < 0.5259） |
| GSM8K 至少 +3 pt | **过**（+3.79） |
| GSM 回升高于 logit 对照 | **过**（0.752 ≫ 0.466） |

**M1 判决：`fail_m1`。**

## 解读（不要事后改判据）

1. **值得保留的信号**：注意力锚定相对 logit 对照是对的——同样喂 GSM8K，logit 把下游干崩了，anchor 却涨了分。
2. **当前不够立项的地方**：遗忘质量有可测的轻微回退；按写死的 M1 不能记 proceed。
3. **若继续做**：应在「FE 持平」约束下调 μ / 锚定层 / 混合比，而不是放宽 FE 门。
